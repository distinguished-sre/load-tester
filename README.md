# Курс нагрузочного тестирования переехал

Курс теперь живёт на сайте **«Обучение»** вместе с курсом DevOps и новым курсом «Мониторинг и SRE»:

- сайт курса: https://distinguished-sre.github.io/learning/load-tester/
- все курсы: https://distinguished-sre.github.io/learning/
- репозиторий: https://github.com/distinguished-sre/learning, курс в папке `load-tester/`

Учебный стенд «Магазин» теперь берётся из нового репозитория:

```bash
git clone https://github.com/distinguished-sre/learning.git ~/learning
cd ~/learning/load-tester/project/shop
```

Уроки те же, поменялись только адреса. Старые ссылки на уроки ведут на страницу со ссылкой на тот же урок на новом сайте. Отметки о пройденных уроках и результаты тестов сохранились.

Новые уроки и исправления появляются только в репозитории `learning`. Курс в том виде, каким он был до переезда, лежит в этом репозитории под тегом [`before-move`](https://github.com/distinguished-sre/load-tester/tree/before-move).
